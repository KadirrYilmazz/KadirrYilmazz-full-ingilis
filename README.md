# FULL İNGİLİŞ

LGS İngilizce kelime ezberleme odaklı web uygulaması.

İlk UI sürümünde Türkçe dashboard, 10 ünite, görsel hafıza odaklı tasarım, ilerleme ve tekrar alanları bulunur.

Not: Ünite kelime sayıları ve ilerleme değerleri ilk UI prototip verileridir; gerçek müfredat kelime havuzu doğrulanarak sonraki adımda eklenecektir.
